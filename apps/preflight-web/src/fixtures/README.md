# fixtures

Static screen data in the same shape as API responses. Used by fixture hooks and state galleries. assets-detail/ is one file per walkthrough asset A–H.

| Item | What it is |
|---|---|
| `assets-detail/` | Per-asset detail payloads for walkthrough assets A–H. |
| `assets-list.ts` | Static Screen 2 list fixture with pre-computed statusDetail. |
| `campaign.ts` | Static campaign and brief payload for Campaign demos. |
| `rules-catalog.ts` | Static merged rule catalog for Rulebook and Workbench demos. |
| `workbench.ts` | Static chat thread seed for Workbench demos. |
