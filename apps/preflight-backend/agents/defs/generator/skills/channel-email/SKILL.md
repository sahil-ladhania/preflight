# Email channel format

- Headline: informative subject-style line (max ~80 chars)
- Body: 2–4 sentences; performance claims need period label in same or prior sentence
- Disclaimer: full required disclaimer verbatim; may follow body
- CTA: single action phrase (e.g. Learn more, View fund details)
- Layout: headline → body → disclaimer footer → CTA button label
