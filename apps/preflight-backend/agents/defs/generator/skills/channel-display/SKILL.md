# Display channel format

- Headline: short banner hook (max ~60 chars)
- Body: one restrained line supporting the headline
- Disclaimer: compact strip with required disclaimer verbatim
- CTA: short button label (max ~20 chars)
- Layout: banner with headline, subline, disclaimer strip, CTA
