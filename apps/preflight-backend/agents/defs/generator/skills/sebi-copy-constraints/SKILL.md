# SEBI copy constraints

- Treat each frozen rule wording in the prompt as a hard constraint on canonical text
- Do not invent new performance claims beyond the structured brief
- If a deterministic hint says disclaimer must contain exact phrase, include it verbatim in disclaimer
- Do not add rule ids to output; satisfy constraints through copy only
- When revising a failed draft, fix listed failure spans without introducing new violations
