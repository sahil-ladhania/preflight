# LinkedIn channel format

## When to load

Load when the per-call prompt specifies `channel: linkedin`. Ignore for other channels.

## Hard caps (Bluepeak kit)

- **headline**: max **120** characters — count before output; shorten if over
- **layoutNotes**: Card: headline hook, body paragraph, disclaimer line, CTA link

## Field constraints

- **headline**: professional hook; must fit within 120 characters
- **body**: one short paragraph; credible tone, no sales pressure
- **disclaimer**: one line with required disclaimer verbatim
- **cta**: link-style phrase (e.g. Read the offer document, View fund page)

## Layout mental model

```
[Headline — hook]
[Body — single paragraph]
[Disclaimer line]
[CTA link text]
```

## Do

- Open with substance relevant to the brief objective
- Cite performance with period when figures appear in the brief
- Keep tone peer-to-peer professional (B2B credible, not viral)

## Don't

- Use hashtag stacks, emoji floods, or engagement bait
- Write body as bullet list unless brief demands it
- Use urgency language (limited slots, ending soon)

## Never

- Apply LinkedIn card layout to email or display banners
- Emit rule ids or compile hints
- Shorten the required disclaimer
