# golden

Fixed snippets and expected verdicts. det.json must pass 100% or the suite fails. judgement.json drives live judge evals with a published agreement bar.

| Item | What it is |
|---|---|
| `det.json` | Deterministic golden cases; 100% pass is mandatory. |
| `golden-report.md` | Generated summary of det golden case outcomes. |
| `golden.test.ts` | Vitest runner for det and judgement golden files. |
| `judgement.json` | ≥10 judgement golden cases for live three-run agreement checks. |
| `eval-report.json` | Generated by `npm run evals -w preflight-backend` (gitignored). |

**Acceptance:** judgement agreement ≥85% across all runs; generator/extractor structural checks must pass. Gate is local only (`exit 1`); no CI OpenAI job.

**Run:** `npm run evals -w preflight-backend` (requires `OPENAI_API_KEY` in root `.env`).
