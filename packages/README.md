# packages

Shared workspaces used by the apps. rules is the zero-dependency matching engine. schemas is the HTTP and status contract. eslint-config and typescript-config are shared lint and compiler settings.

| Item | What it is |
|---|---|
| `eslint-config/` | Shared ESLint flat configs for the monorepo. |
| `rules/` | Zero-dependency deterministic matching engine. |
| `schemas/` | Zod wire DTOs and foldStatus shared by web and backend. |
| `typescript-config/` | Shared TypeScript compiler base configs. |
